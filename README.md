# 社团网页 · 起始版

解压后双击 `index.html`，或用 VS Code 的 Live Server 打开。无需安装 Node/npm。

课堂只复制 `index.html`、`style.css`、`script.js` 三个文件到已经 clone 的仓库根目录。保留 GitHub 创建的 README.md；不要复制本说明去覆盖它，不要复制文件夹外壳，不要触碰隐藏的 `.git`。

按钮会显示选择方向的演示回执；不联网、不保存、不是真实报名。刷新回执清空。

第一次提交保存三文件。第二次提交只把 `index.html` 中活动须知改成：

```html
<p id="notice">活动须知：请提前打开 VS Code，准备 GitHub 账号，并带上一个想分享的小作品。</p>
```

保存并刷新后，检查 diff，仅提交 `index.html`。对应完成示例在上级 `solutions/`；CSS 和 JS 无须修改。
